# Імпорт станів у Figma

`states-static.html` — статична версія дошки станів (без скриптів), готова до імпорту в Figma:

- через Figma MCP `html_to_figma` з селектором `.vbx-sec` (6 секцій: P1-A, P1-B, P1-C, P2-A, P2-B, P2-C) або `.vbx-frame` (84 фрейми, імпорт партіями по 20);
- або вручну плагіном html.to.design (імпорт за URL `/figma-import/states-static.html`).

Шрифти: Lora та Montserrat (є у Figma).
