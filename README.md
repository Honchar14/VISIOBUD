# Visiobud · демо pop-up

Інтерактивний прототип двох pop-up на живій головній сторінці visiobud.com.

1. **Pop-up 1 «Потрібна консультація лікаря?»** — відкривається кнопками запису на сайті.
2. **Pop-up 2 «Чи є у ваших очей ознаки перенапруження?»** — квіз із 3 питань, з’являється перед футером.

Для кожного pop-up — 3 варіанти дизайну (A · Фото-спліт, B · Мінімал, C · Бренд-акцент), перемикаються на панелі внизу.

Як це працює: `index.html` — розмітка головної сторінки visiobud.com (стилі, зображення й скрипти підтягуються з visiobud.com через `<base>`), без аналітики та reCAPTCHA. Поверх неї — шар демо (`#vb`): pop-up, панель, підказки. Форми нікуди не надсилають дані, переходи на інші сторінки вимкнені.
Сторінка закрита від індексації (`noindex`, `robots.txt`).
