# Visiobud · демо pop-up

Інтерактивний прототип фінальних правок на живій головній сторінці visiobud.com.

1. **Pop-up «Потрібна консультація лікаря?»** — фінальний варіант (A + C): фото лікаря з фоном клініки й білим градієнтом, підложка з логотипом над заголовком, поле + кнопка «Надіслати» в один рядок, декоративні кола. Відкривається будь-якою кнопкою запису на сайті.
2. **Форма «Чи є у ваших очей ознаки перенапруження?»** — тепер не pop-up, а відкрита секція перед футером (на головній і на сторінках усіх послуг). Фото клініки, переваги з кольоровими іконками, помаранчева кнопка. Результат має кольорову шапку з іконкою (зелений / помаранчевий / червоний), без відповідей користувача, текст під заголовком виділено.

Як це працює: `index.html` — розмітка головної сторінки visiobud.com (стилі, зображення й скрипти підтягуються з visiobud.com через `<base>`), без аналітики та reCAPTCHA. Поверх неї — шар демо (`#vb`, `#vbx-test`). Форми нікуди не надсилають дані, переходи на інші сторінки вимкнені.

Папки `states/` і `figma-import/` — попередня версія (3 варіанти дизайну), залишені для історії.

Сторінка закрита від індексації (`noindex`, `robots.txt`).
