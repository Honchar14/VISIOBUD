# Visiobud · демо pop-up

Інтерактивний прототип двох pop-up для сайту visiobud.com (варіант A):

1. **«Потрібна консультація лікаря?»** — відкривається кнопками запису на сторінці.
2. **«Чи є у ваших очей ознаки перенапруження?»** — квіз із 3 питань, з’являється перед футером.

Сайт під pop-up — знімок головної сторінки; форми нікуди не надсилають дані.
Сторінка закрита від індексації (`noindex`, `robots.txt`).

Статичний сайт без збірки: `index.html`. Деплой — Vercel.
